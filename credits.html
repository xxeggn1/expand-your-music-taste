Designed and built Expand Your Music Taste — concept, quiz logic, visual direction, and the Last.fm integration that powers every result.

Last.fm API

Every album title, release year, genre tag, cover image, and description shown in your results is fetched live from Last.fm — nothing on the results page is a hand-picked or manual list.

A plain, dependency-free front end

No frameworks, no build step — just HTML, CSS, and JavaScript talking directly to an API.

HTML5 CSS3 JavaScript (ES6+) Fetch API SVG Last.fm REST API Google Fonts

Fraunces, IBM Plex Sans & IBM Plex Mono

Fraunces carries the headlines, IBM Plex Sans handles body copy, and IBM Plex Mono is reserved for tags, metadata, and anything that reads like liner notes.

Automatic, not manual

Your genre answer plus the following nine answers become a set of Last.fm tags. The site queries those tags, scores every album by how many of your answers it matches, filters for era where possible, and hands back a maximum of three pages of results — never a fixed, pre-written list.
